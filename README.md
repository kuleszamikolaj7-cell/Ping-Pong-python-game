# 🏓 Python Ping Pong

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-Finished-brightgreen)

A simple **two-player Ping Pong game** created in Python using the built-in `turtle` module.

The project was created as one of my first Python projects to practice basic programming concepts and simple game mechanics.

## 🎮 Controls

| Player | Action | Key |
|:---:|---|:---:|
| 🔴 Player 1 | Move up | `W` |
| 🔴 Player 1 | Move down | `S` |
| 🔴 Player 2 | Move up | `↑` |
| 🔴 Player 2 | Move down | `↓` |

---

## ✨ Features

- 🏓 Two-player local gameplay
- ⌨️ Keyboard controls
- ⚪ Moving ball
- 💥 Paddle collision detection
- 🧱 Ball bouncing from the screen borders
- 🏆 Score counter
- 🔄 Automatic position reset after scoring

---

## 🛠 Technologies

- **Python**
- **Turtle Graphics**

No external Python packages are required.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kuleszamikolaj7-cell/Ping-Pong-python-game.git
```

### 2. Open the project folder

```bash
cd Ping-Pong-python-game
```

### 3. Run the game

```bash
python ping_pong.py
```

Make sure you have Python installed on your computer.
